# scalp-sebum-posters

두피 피지(sebum)와 두피 세균 군집에 관한 학회 포스터의 분석 코드입니다. **포스터마다 폴더를 나눴습니다.**

| 폴더 | 학회 | 포스터 주제 |
|---|---|---|
| [msk-2026](msk-2026/) | 2026 International Meeting of the Microbiological Society of Korea (MSK 2026) | 수분은 다양성을, 피지는 우점 속 사이 균형을 결정한다 — 두피 세균 군집의 독립적인 두 생리 축 |

각 폴더의 README 에 분석 순서, 필요한 입력, 실행 환경이 적혀 있습니다.

## 데이터

사람 대상 시료라 **원자료와 임상 지표는 공개하지 않습니다.** 이 저장소에는 코드만 있습니다.
외부 검증에 쓴 공개 코호트(NCBI SRA 등)의 번호는 각 폴더 README 에 적었습니다.
